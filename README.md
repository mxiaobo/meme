# 港股打新结算系统

本地浏览器使用的港股打新中签管理工具，覆盖三大模块：

- **账户参与人管理**（姓名 / 证券账号 / 预支工资流水）
- **中签管理**（项目 + 各参与人独立成本与卖出收入）
- **月度结算**（按"卖出月归属法 + 每人独立净额法"自动结算，可反结算）

## 业务规则

- 上家（操作员）拿 70%，账户参与人拿 30%；亏损全部由上家承担
- 月度结算按 `卖出日期` 所在月份归属
- 单参与人公式：
  - `本月净利润 = Σ(卖出收入 - 成本)`（仅本月已卖出的中签记录）
  - `应得分红 = max(净利润, 0) × 30%`
  - `期末预支 = max(0, 期初预支 − 应得分红)`
  - `实发 = 应得分红 − 期初预支`（可为负，表示仍欠预支）
- 结算后涉及的中签记录按"条目"锁定，可按月反结算
- 任何 `卖出日期` 落入"已结算月份"的修改都会被阻止

## 运行

```bash
pip install -r requirements.txt
python app.py
# 浏览器访问 http://127.0.0.1:5000/
```

## 数据存储

- 数据库文件：`data/portfolio.db`
- 自动备份：每次结算 / 反结算前复制到 `data/backups/`
- 全部敏感数据存本地，不上传任何外部服务

templates/              # Jinja2 模板
static/style.css        # 样式
data/                   # 数据库与备份（已 gitignore）
